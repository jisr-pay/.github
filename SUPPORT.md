# Support

This project is Testnet-only and maintained by two human owners. Support is
best-effort and focused on documentation and issues that help the project.

- **Live app:** https://jisr-pay.vercel.app/
- **Documentation:** see the `docs/` directory in each repository
  (`jisr-web/docs` holds the collaboration plan, setup guide, and handoff).
- **Bugs, questions, features:** open an issue in the relevant repository.
- **Corporate inquiries:** mention an organization owner in a private issue.

For security reports, use [SECURITY.md](SECURITY.md). For how to contribute,
see [CONTRIBUTING.md](CONTRIBUTING.md).
