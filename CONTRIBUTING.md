# Contributing

Thanks for considering a contribution. This project is intentionally small,
Testnet-only, and maintained by two human owners.

## Before you start

- Read the collaboration and ownership plan:
  [jisr-web/docs/COLLABORATION_PLAN.md](https://github.com/jisr-pay/jisr-web/blob/main/docs/COLLABORATION_PLAN.md),
  and the setup guide
  [jisr-web/docs/ORG_SETUP.md](https://github.com/jisr-pay/jisr-web/blob/main/docs/ORG_SETUP.md).
- `main` branches are protected and require reviewed pull requests — never push
  directly, and never force-push a stale clone over the rewritten history.
- Validate tests, typechecks, and builds locally before opening a PR.

## Steps

1. Find or open an issue that describes the change.
2. Create a branch from a fresh clone of `origin/main`.
3. Make small, focused commits in the repository's existing style.
4. Open a pull request with a description and any relevant acceptance criteria.
5. Wait for a review from one of the owners.
