# Jisr Pay

![Jisr Pay](https://raw.githubusercontent.com/jisr-pay/.github/main/assets/icon.svg)

**Jisr Pay — جسر — building bridges across borders on Stellar Testnet.**

An open experiment in cross-border payments: a [web client](https://github.com/jisr-pay/jisr-web), an [SDK](https://github.com/jisr-pay/jisr-sdk) of reusable payment primitives, and an internal [settlement-tracking API](https://github.com/jisr-pay/jisr-api).

- Live Testnet web app: https://jisr-pay.vercel.app/
- Testnet only — never use with real funds.
- Collaboration plan and ownership: [jisr-web/docs/COLLABORATION_PLAN.md](https://github.com/jisr-pay/jisr-web/blob/main/docs/COLLABORATION_PLAN.md)
